Issue #23 — env-tag column alignment, Variant A (per-position width)

The fix. Each path-position index reserves the same column-1 width across every row in a service block, computed as the max .env-tag intrinsic width at that exact position. Result: nth deployment cell aligns with nth deployment cell, label-text-length-invariant; horizontally the column is as narrow as it can possibly be for each position. Mirrors swim-lane .depth-slot behaviour.

Scope. Per-service-block only. No cross-service alignment. Bug source: frontend/dashboard/src/app/workflow-rows-layout.component.ts:236-251 wraps each env cell in a .leaf-pair; styles.css:182-187 styles it as an independent grid with grid-template-columns: auto var(--leaf-width).
