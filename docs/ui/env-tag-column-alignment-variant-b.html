Issue #23 — env-tag column alignment, Variant B (shared-max width)

The fix. A single column-1 width per service block, computed as the max .env-tag intrinsic width across ALL positions and ALL rows. Every .leaf-pair in the block uses the same value; nth deployment cell aligns with nth deployment cell. Slightly wider service blocks than Variant A (every position reserves the widest env-tag anywhere in the block), but no position-index plumbing in the template.

Scope. Per-service-block only. No cross-service alignment. Bug source: frontend/dashboard/src/app/workflow-rows-layout.component.ts:236-251 wraps each env cell in a .leaf-pair; styles.css:182-187 styles it as an independent grid with grid-template-columns: auto var(--leaf-width).
