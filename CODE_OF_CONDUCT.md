# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Scope

Applies to all project spaces — GitHub issues, pull requests, discussions, and the project's hosted documentation.

## Reporting

Confidential reports: open a private security advisory at <https://github.com/kostiantyn-matsebora/deployment-dashboard/security/advisories/new>.

## Enforcement

The maintainer reviews each report and follows the Contributor Covenant's enforcement guidance.
